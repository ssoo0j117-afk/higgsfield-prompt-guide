# 🎨 higgsfield-prompt-guide

초등학생 대상 학습 서비스의 캐릭터 4종(다정파·기분파·분석파·인상파)을 힉스필드로
일관성 있게 생성하기 위한 프로젝트.
캐릭터 이름만 말하면 Element가 자동 바인딩되고, 검증된 프롬프트 템플릿으로
일관된 스타일이 유지된다.

## 셋업 (처음 한 번만)

1. **레포 클론**
   ```bash
   git clone https://github.com/<YOUR_GITHUB_ID>/higgsfield-prompt-guide.git
   cd higgsfield-prompt-guide
   ```
2. **클로드코드 실행**
   ```bash
   claude
   ```
3. **힉스필드 연결 확인** — 계정에 힉스필드 MCP/커넥터가 연결돼 있어야 캐릭터 생성이 가능하다.

## 사용법

한국어로 요청하면 된다:

```
다정파가 선물 상자 들고 있는 팝업 이미지 만들어줘
기분파랑 분석파가 같이 있는 3D 굿즈컷
인상파 표정 다양하게 4개
```

클로드가 영문 구조화 프롬프트로 변환 → 생성 전 3~4줄 요약을 보여주고 진행한다.
전체 프롬프트가 궁금하면 "전문 보여줘".

## 폴더 구조

| 경로 | 내용 |
|------|------|
| `CLAUDE.md` | 워크플로우·Element 바인딩·프롬프트 구조 규칙 (클로드가 자동 로드) |
| `style/characters.md` | 캐릭터 4종 + Element ID(2D/3D) + 영문 외형 블록 + 시그니처 락 |
| `templates/character-scene.md` | 씬 조립 골격 (Scene/Cast/텍스트 예약 영역/Style 스위치/Negative) |
| `prompts/` | 확정된 프롬프트 로그 — 새 요청 시 재사용 |

## 팀 규칙 (중요)

- **작업 시작 전 `git pull`** — 다른 사람이 반영한 규칙 개선을 받는다.
- **결과가 잘못 나와서 고쳤다면**, 클로드가 그 규칙을 파일에 반영했는지 확인하고 **커밋 + 푸시**한다.
  이 학습 루프가 쌓일수록 생성 정확도가 올라간다.
- 캐릭터를 새로 등록하면 `style/characters.md`에 Element ID를 추가한다.
