# 프롬프트 로그

확정된(사용자 OK 받은) 생성 건은 여기 저장한다. 새 요청 시 유사 사례를 먼저 검색해 재사용한다.

- 파일명: `YYYY-MM-DD-슬러그.md`
- 포맷:

```markdown
# {제목}
- 날짜: YYYY-MM-DD
- 요청(한국어): {원문}
- 렌더/비율: 2D 또는 3D / {WxH 또는 비율}
- Elements: 다정파, 분석파 (<<<id>>> ...)
- 결과: OK (n차 시도)

## 최종 프롬프트
{영문 전문}

## 시행착오 메모
- {실패 원인 → 어떻게 고쳤는지. 재사용 가능한 규칙이면 style/templates 파일에도 반영했는지 체크}
```
