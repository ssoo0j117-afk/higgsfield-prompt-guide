# 분석파 색상 보정 (레퍼런스 기준 색상 확정)

- 날짜: 2026-09-10
- 요청(한국어): "분석파는 내가 첨부한 사진처럼 색상 유지해줘!! 기억해서 로그까지 남겨" — 돋보기 들고 윙크하는 분석파 3D 레퍼런스 이미지 첨부 (사용자 소스 이미지, 이 레포에는 파일 첨부 안 함 — 색상값만 기록)
- 유형: 생성 로그가 아니라 **색상 기준 확정/보정** — `style/characters.md`의 분석파 hood/face patch 헥스 값을 이 레퍼런스 기준으로 영구 수정.

## 변경 내용
| 항목 | 기존 | 변경 후 |
|---|---|---|
| hood/outer | `#40ADA3` (다소 muted한 틸) | `#2FC1C2` (더 밝고 선명한 터콰이즈) |
| face patch | `#A0D7D0` | `#B3EDE8` (더 밝은 민트 아쿠아) |
| 안경테 | `#0A2540` (변경 없음) | `#0A2540` (레퍼런스와 일치, 유지) |

`style/characters.md`의 분석파(BUNSEOK) 블록과 버전 이력에 반영 완료.

## 시행착오 메모
- 이번 건은 프롬프트 재시도가 아니라 **기준 색상 자체가 실제로 부정확했던 케이스**. 지금까지 채도 문제(전체적으로 흐리다)는 Style 블록의 "vivid/saturated" 강도로 조정했지만, 이번엔 **특정 캐릭터의 base hex 자체가 레퍼런스와 다르다**는 지적이라 캐릭터 블록의 색상값을 직접 교체하는 방식으로 대응.
- 앞으로 분석파가 등장하는 모든 씬(3D)은 자동으로 이 새 색상(`#2FC1C2` / `#B3EDE8`)을 사용하게 된다 — `style/characters.md`를 참조하는 모든 프롬프트에 공통 적용.
- 2D 분석파 Element(`94fe7ad2-...`)는 이번 색상 보정 대상에 포함되지 않았음 — 2D 씬에서 색상이 안 맞으면 추후 별도 확인 필요.
